# Jyotish для macOS — релизы

Здесь только готовые сборки приложения **Jyotish** (ведическая астрология: карта и варги, даши, транзиты,
панчанга и календарь, мухурта, варшапхала, совместимость, чат с ИИ на своём ключе). Код — в отдельном закрытом репозитории.

## Требования

- Mac на Apple Silicon (M1 и новее), macOS 15 или новее.

## Установка и обновление

В Терминале:

```bash
curl -fsSL https://github.com/evgeniybal/jyotish-releases/releases/latest/download/install.sh | bash
```

Скрипт скачивает последний DMG, ставит Jyotish в «Программы» и запускает его. Если приложение уже стоит,
перед заменой база карт копируется в `~/Library/Application Support/com.yevhenbal.jyotish/Backups/`.

Дальше обновления — прямо в приложении: **Jyotish → «Проверить обновления…»** (и само раз в день при запуске).

### Вручную

DMG каждой версии — во вкладке [Releases](https://github.com/evgeniybal/jyotish-releases/releases).
Приложение не нотаризовано (подпись без аккаунта разработчика), поэтому после скачивания браузером macOS
его не откроет: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
Установка через `install.sh` этого шага не требует.

## Чат с ИИ

Нужен свой ключ API (DeepSeek, OpenAI, Gemini или свой OpenAI-совместимый сервер): **Настройки (⌘,) → ИИ**.
Ключ хранится в Связке ключей macOS. После обновления приложения macOS один раз спросит пароль для доступа
к ключу — нажмите «Разрешить всегда».
